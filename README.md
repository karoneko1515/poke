# 🎴 ポケモンカード資産管理アプリ

ポケモンカードBOX等の資産の推移を確認・管理するGUIアプリケーションです。

## 🎯 主な機能

### ✨ 基本機能
- **商品登録機能**: 購入日、購入金額、定価、画像を登録
- **市場価格更新**: 商品ごとの市場価格を日付と共に記録・蓄積
- **グラフ表示**:
  - ポートフォリオ全体の推移グラフ
  - 個別商品の価格推移グラフ
- **売却機能**: データを保持しながら売却処理

### 🔍 検索・フィルタ機能
- **商品名検索**: 部分一致で商品を検索
- **期間フィルタ**: 購入日の範囲で絞り込み
- **検索結果の即座反映**: リアルタイムで商品一覧を更新

### 📊 詳細統計・損益計算
- **ROI計算**: 保有中商品、総合ROIを自動計算
- **損益詳細**: 商品ごとの詳細な損益情報を一覧表示
- **パフォーマンス分析**: 最高益商品、平均保有期間などの統計
- **損益率表示**: パーセンテージでの損益率を表示

### 📈 ダッシュボード機能
- **総合サマリー**: 総投資額、現在価値、含み損益、総損益
- **パフォーマンス統計**: ROI、最高益商品の表示
- **ポートフォリオ情報**: 保有商品数、平均保有期間、実現損益

## 💻 使用方法

1. アプリケーションを起動すると、ブラウザで http://localhost:8000 が開きます
2. **ダッシュボード**で全体の資産状況を確認
3. **商品登録**で新しいポケモンカードを追加
4. **市場価格更新**で定期的に現在の価格を記録
5. **グラフ**でポートフォリオや個別商品の推移を視覚化
6. **検索・フィルタ**で特定の商品を素早く検索
7. **損益詳細**で詳細な損益分析を確認
8. **売却**機能で商品を売却処理

## 📱 画面構成

### 🏠 ダッシュボード
- **サマリーカード**: 主要な財務指標を4つのカードで表示
- **パフォーマンス統計**: ROI、最高益商品の情報
- **ポートフォリオ情報**: 保有状況、期間、損益の詳細

### 📦 商品一覧
- **検索・フィルタ**: 商品名、購入日での絞り込み機能
- **詳細表示**: 画像、価格、損益、損益率を一覧表示
- **売却ボタン**: 各商品に売却処理ボタン

### ➕ 商品登録
- **基本情報入力**: 名前、日付、価格の入力
- **画像アップロード**: 商品画像の登録とプレビュー

### 📈 市場価格更新
- **商品選択**: プルダウンから商品を選択
- **価格履歴**: 過去の価格履歴を表示
- **日付指定**: 価格の取得日を指定

### 📊 グラフ
- **ポートフォリオ推移**: 全体の投資額vs現在価値
- **個別商品推移**: 選択した商品の価格変動

### 💰 損益詳細
- **統合損益表**: 保有中・売却済みを問わず全商品の損益詳細
- **ステータス表示**: 保有中/売却済みのバッジ表示
- **パフォーマンス順**: 損益率の高い順で表示

## 💾 データ保存

- **SQLiteデータベース**: `pokemon_cards.db` ファイルに全データを保存
- **商品画像**: `static/images/` フォルダに保存
- **バックアップ**: データベースファイルをコピーするだけで簡単バックアップ

## 🎨 技術仕様

- **フロントエンド**: HTML5, CSS3, JavaScript, Bootstrap 5
- **バックエンド**: Python 3, Eel

## 🆘 トラブルシューティング

### ❌ アプリが起動しない
- 仮想環境が正しく作成されているか確認
- 必要なパッケージがインストールされているか確認
- Python 3.8以上がインストールされているか確認

### 🌐 ブラウザが開かない
- 手動で http://localhost:8000 にアクセス
- ブラウザのセキュリティ設定を確認

### 📸 画像が表示されない
- `static/images/` フォルダの権限を確認
- ブラウザのキャッシュをクリア
